# Development stage

Pepe is v0.0 and pre-release. The maintainer will explicitly decide when v0.1 begins.

- Do not create version tags, GitHub releases, or published release artifacts unless explicitly requested.
- Build and deploy current source directly; identify deployments by commit SHA.
- Do not add backward compatibility layers, legacy API support, or historical schema migrations during this stage.
- Preserve existing work and credentials. Do not reset deployed state without explicit authorization.
